\# SupportSense AI



An AI-powered customer-support ticket intelligence copilot.



SupportSense AI will classify support tickets by category and urgency, retrieve relevant policy documents, and generate a grounded response draft. The project demonstrates practical Data Science, Machine Learning, LLM, API, testing, and deployment skills.



\## Project Status



Work in progress - Day 1: environment and project structure.



\## Planned Features



\- Customer-ticket data cleaning and exploratory data analysis

\- Machine-learning model for ticket category classification

\- Priority prediction with confidence scores

\- Model evaluation using macro F1 score and a confusion matrix

\- Retrieval-Augmented Generation (RAG) for policy-document search

\- Groq LLM-generated response drafts with source references

\- FastAPI backend and simple web interface

\- Automated tests, Docker, and GitHub Actions CI

\- Live deployment and interactive demo



\## Planned Tech Stack



Python, pandas, scikit-learn, FastAPI, Groq LLM, pytest, Docker, GitHub Actions, and GitHub.
